# 한국 법인 회계팀 스킬 (kr-accounting)

한국 법인 회계팀이 다루는 업무 전반을 한국 기준(K-IFRS·일반기업회계기준, 한국 세법, 홈택스)으로 처리하는 Claude 스킬입니다.

## 다루는 업무

| 영역 | 내용 |
|---|---|
| 결산 | 분개, 월·분기·연 결산, 계정 대사 |
| 부가가치세 | 매출·매입 집계, 홈택스 대사, 불공제 판정 |
| 급여·원천세 | 원천세, 4대보험, 퇴직금, 연말정산 |
| 법인세 | 세무조정 체크리스트, 세액공제·감면 검토, 이연법인세 |
| 재무보고·감사 | 재무제표, 주석, PBC 리스트, 공시 |
| 자금·FP&A | 자금일보, 자금수지, 예산, 차이분석, 경영보고 |
| 세무 일정 | 월별·연간 신고 기한 안내 |

## 세율·요율을 매년 고치지 않아도 되는 이유

이 스킬에는 세율, 공제 한도, 4대보험 요율 같은 숫자가 들어 있지 않습니다.
필요할 때마다 국가법령정보센터, 국세청, 4대보험 공단 등 **공식 출처에서 해당 연도 값을 찾아 쓰고**, 결과물에 출처와 기준연도를 남깁니다.
그래서 **웹 검색을 켜고** 사용해야 합니다.

## 설치

### Claude Code

```bash
claude plugin marketplace add Crong-dev/kr-accounting-plugins
claude plugin install kr-accounting@kr-accounting-plugins
```

업데이트:

```bash
claude plugin marketplace update kr-accounting-plugins
```

### Claude 앱 (claude.ai, 데스크톱, 모바일)

1. 이 저장소의 [Releases](https://github.com/Crong-dev/kr-accounting-plugins/releases)에서 `kr-accounting-team.zip`을 내려받습니다.
2. Claude 설정의 스킬 메뉴에서 zip 파일을 업로드합니다.
3. 웹 검색이 켜져 있는지 확인합니다.

## 사용 예시

- "10월 결산 체크리스트 만들어줘"
- "이 은행 거래내역이랑 원장 대사해줘" (엑셀 첨부)
- "2기 예정 부가세 신고 준비해줘"
- "이번 달 급여대장으로 원천세 계산해줘" (엑셀 첨부)
- "법인세 세무조정 체크리스트 만들어줘"
- "감사인 PBC 리스트 정리해줘"
- "이번 달 세무 일정 알려줘"

## 유의사항

이 스킬은 회계팀 업무를 돕는 도구이며 세무·회계 자문이 아닙니다.
세무 신고와 회계 처리의 최종 판단은 담당자, 세무사, 회계사가 해야 합니다.
