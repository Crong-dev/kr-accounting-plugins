# 재무제표 · 주석 · 외부감사 · 공시

|---|---|
| 재무상태표 | 재무상태표 |

## 2. 작성 절차

1. 수정 후 시산표 확정
2. 계정과목 → 재무제표 표시 항목 매핑표 작성(회사 계정과목표 기준)
3. 유동/비유동 분류 (1년 기준, 정상영업주기)
4. 현금흐름표: 간접법 기준으로 영업활동 조정 항목, 투자·재무활동 변동 산출 → 기초·기말 현금 일치 확인
5. 전기 대비 비교 표시, 재분류 시 전기 금액도 재분류
6. 주석 작성: 회계정책, 주요 계정 명세, 특수관계자 거래, 우발부채·약정, 후속사건
7. 검증: 재무상태표 차대 일치, 당기순이익 ↔ 자본변동표 ↔ 이익잉여금 연결, 현금흐름표 기말현금 ↔ 재무상태표 현금

## 3. 기준 간 주요 차이 (검토 포인트)

- 수익인식: K-IFRS 1115호 5단계 모형
- 리스: K-IFRS 1116호 사용권자산·리스부채 인식
- 금융상품: K-IFRS 1109호 분류·기대신용손실
- 퇴직급여: K-IFRS 1019호 보험수리적 평가
- 일반기업회계기준은 위 항목에서 간소화된 처리 허용

적용 기준은 SKILL.md의 회사 정보에 따른다. 쟁점이 있으면 해당 기준서 문단을 함께 적는다.

## 4. 외부감사 대응

### PBC(Prepared By Client) 리스트 기본 항목

| 영역 | 자료 |
|---|---|
| 일반 | 시산표, 총계정원장, 계정별 보조원장, 조직도, 이사회·주총 의사록 |
| 현금 | 은행 잔액증명서, 은행조회서 회신 협조 |
| 채권 | 거래처별 잔액명세, 연령분석표, 채권조회서 |
| 재고 | 실사 결과, 평가 내역, 수불부 |
| 유형·무형자산 | 고정자산대장, 취득·처분 증빙, 감가상각 명세 |
| 채무 | 거래처별 잔액명세, 차입금 약정서, 이자 계산 |
| 충당부채 | 퇴직급여 계산, 소송 현황, 보증 내역 |
| 수익·비용 | 주요 계약서, 매출 cut-off 자료, 비용 증빙 샘플 |
| 세무 | 법인세 신고서, 세무조정계산서, 부가세 신고서 |
| 특수관계자 | 특수관계자 목록, 거래·잔액 명세 |

### 대응 원칙
- 요청 자료별 담당자·기한·제출 여부를 관리표로 관리한다.
- 감사인 수정사항(AJE)은 원인과 재발 방지 방안을 기록한다.
- 경영진 확인서 문구는 사실관계와 맞는지 확인한다.

## 5. 공시 (해당 시)

- 외부감사 대상 비상장: 감사보고서 DART 제출
- 상장사: 분·반기·사업보고서, 수시공시 — 일정과 서식은 DART·거래소 기준 확인

## 6. 결과물

- 재무제표 초안(엑셀, 계정 매핑과 수식 유지)
- 주석 초안(문서)
- 현금흐름표 작성 워크시트
- PBC 관리표
- 검증 체크리스트 결과
