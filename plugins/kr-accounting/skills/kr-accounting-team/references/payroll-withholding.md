# 급여 · 원천세 · 4대보험 · 연말정산

## 1. 월 급여 처리 흐름

1. 급여대장 확정: 기본급, 수당(과세/비과세 구분), 상여, 공제 항목
2. 비과세 소득 판정: 식대, 자가운전보조금, 연구활동비, 출산·보육수당 등 — 한도는 해당 연도 기준 확인 `[확인 필요]`
3. 근로소득세: 간이세액표(해당 연도)에 따라 계산. 원천징수 비율(80/100/120%) 선택 여부 확인
4. 지방소득세: 근로소득세의 10%
5. 4대보험 근로자 부담분: 국민연금, 건강보험, 장기요양보험, 고용보험 — 요율은 해당 연도 공단 고시 확인
6. 급여 분개 예시

| 차변 | 대변 |
|---|---|
| 급여 (총지급액) | 예수금(소득세·지방소득세) |
| | 예수금(4대보험 근로자분) |
| | 보통예금(실지급액) |
| 복리후생비/보험료(4대보험 회사분) | 미지급비용 또는 예수금 |

7. 차변 합계 = 대변 합계, 실지급액 = 급여대장 실수령 합계를 계산으로 확인한다.

## 2. 원천세 신고·납부

- 매월 납부: 지급일이 속한 달의 다음 달 10일
- 반기 납부: 승인받은 소규모 사업장만 (7/10, 1/10)
- 원천징수이행상황신고서 작성: 근로(간이세액·중도퇴사·일용·연말정산), 퇴직, 사업, 기타, 이자·배당
- 사업소득(프리랜서) 3.3%, 기타소득 필요경비 공제 후 세율 적용 — 세율은 해당 연도 확인
- 지급명세서·간이지급명세서 제출 주기는 최근 개정이 잦으므로 해당 연도 국세청 안내로 확인 `[확인 필요]`

## 3. 4대보험

- 취득·상실 신고: 입·퇴사 시 기한 내 신고
- 보수총액 신고: 건강보험·고용/산재보험 연 1회(3월) — 보험료 정산
- 건강보험 연말정산 결과에 따른 정산분 반영
- 고지서 금액 ↔ 급여 공제액 + 회사부담분 대사

## 4. 퇴직금

- 퇴직급여 계산: 평균임금 × 30일 × 근속연수
- 퇴직소득세: 근속연수공제, 환산급여공제 등 단계 계산 — 해당 연도 공제표 확인
- DC형은 부담금 납입, DB형은 퇴직연금 지급분과 회사 지급분 구분

## 5. 연말정산 (1~2월)

| 단계 | 작업 |
|---|---|
| 1월 초 | 직원 안내, 간소화 자료 제출 일정 공지 |
| 1월 중순 | 간소화 자료·공제신고서 수집 |
| 1월 말~2월 | 공제 검토, 정산 계산, 2월 급여 반영(환급/추징) |
| 3월 10일 | 근로소득 지급명세서 제출, 원천세 신고(연말정산분) |

검토 포인트: 부양가족 중복공제, 소득요건 초과 부양가족, 주택자금공제 요건, 의료비·교육비 대상자.

## 6. 결과물

- 급여 분개, 원천세 계산 검증표(급여대장 대비)
- 원천징수이행상황신고서 항목별 금액 요약
- 4대보험 고지액 대사표
- 연말정산 검토 체크리스트, 직원별 이상 항목 목록

개인정보(주민등록번호 등)가 포함된 파일은 필요한 열만 사용하고 결과물에 그대로 옮기지 않는다.
