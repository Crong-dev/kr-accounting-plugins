# 세율 · 한도 · 요율 실시간 확인 절차

이 스킬에는 세율, 공제·비과세 한도, 4대보험 요율, 신고 기한 숫자를 적어 두지 않는다.
매년 바뀌는 값은 **사용할 때마다 아래 절차로 공식 출처에서 확인**한다. 그래서 스킬을 매년 고치지 않아도 된다.

## 1. 확인 절차

1. **기준 연도를 정한다.** 오늘 날짜가 아니라 거래일·지급일·과세기간·사업연도 기준이다.
   - 예: 2027년 1월에 2026년 연말정산 → 2026년 귀속 기준
   - 예: 2027년 1월 급여 원천징수 → 2027년 간이세액표
2. **공식 출처에서 찾는다.** 아래 2번 표의 출처를 우선한다. 블로그·카페·뉴스는 공식 출처를 찾는 단서로만 쓰고 값의 근거로 쓰지 않는다.
3. **시행 여부를 구분한다.** 세법개정안(기획재정부 발표) → 국회 통과 → 공포·시행 단계가 다르다. 시행일이 기준 연도에 포함되는지 확인한다. 개정안 단계면 "개정 예정"으로 표시한다.
4. **가능하면 두 곳에서 일치하는지 본다.** 예: 국가법령정보센터 조문 + 국세청 안내.
5. **기록한다.** 사용한 값마다 `값 | 기준 연도 | 출처명 | 시행일`을 결과물에 남긴다.
6. **확인하지 못하면 지어내지 않는다.** 출처가 서로 다르거나 찾지 못하면 `[확인 필요]`로 표시하고, 어떤 값들이 충돌하는지 적는다. 학습된 기억 속 숫자를 그대로 쓰지 않는다.

웹 검색을 쓸 수 없는 환경이면 값을 비워 두고 `[확인 필요 — 웹 검색 불가]`로 표시한 뒤, 사용자에게 해당 연도 자료를 첨부해 달라고 요청한다.

## 2. 항목별 공식 출처

| 항목 | 우선 출처 | 보조 출처 |
|---|---|---|
| 법인세율, 세무조정 한도(기업업무추진비, 기부금, 대손 등) | 국가법령정보센터(law.go.kr) 법인세법·시행령 | 국세청(nts.go.kr) 법인세 신고 안내 |
| 세액공제·감면 요건과 공제율 | 국가법령정보센터 조세특례제한법·시행령 | 국세청 세액공제 안내 |
| 부가가치세 기한, 공제·불공제 요건 | 국가법령정보센터 부가가치세법 | 국세청 부가세 신고 안내, 홈택스(hometax.go.kr) |
| 근로소득 간이세액표 | 국세청 근로소득 간이세액표 | 국가법령정보센터 소득세법 시행규칙 |
| 비과세 근로소득 한도(식대 등) | 국가법령정보센터 소득세법·시행령 | 국세청 원천징수 안내 |
| 연말정산 공제 요건·한도 | 국세청 연말정산 안내 자료(해당 귀속연도) | 국가법령정보센터 소득세법 |
| 퇴직소득세 공제 | 국가법령정보센터 소득세법 | 국세청 퇴직소득 안내 |
| 지방소득세 | 국가법령정보센터 지방세법 | 위택스(wetax.go.kr) |
| 국민연금 요율·기준소득월액 상·하한 | 국민연금공단(nps.or.kr) | 4대사회보험 정보연계센터(4insure.or.kr) |
| 건강보험·장기요양보험 요율 | 국민건강보험공단(nhis.or.kr) | 4대사회보험 정보연계센터 |
| 고용보험·산재보험 요율 | 근로복지공단(comwel.or.kr) | 고용노동부(moel.go.kr) |
| 인정이자율(당좌대출이자율) | 국가법령정보센터 법인세법 시행규칙 | 국세청 안내 |
| 세무 신고 기한·일정 | 국세청 월별 세무일정 | 홈택스 신고 안내 |
| 세법 개정 동향 | 기획재정부(moef.go.kr) 세법개정안 | 국세청 개정세법 해설 |
| 회계기준 | 한국회계기준원(kasb.or.kr) | 금융감독원 회계포털 |

## 3. 결과물에 남기는 형식

결과물 끝에 "적용 기준" 표를 붙인다.

| 항목 | 적용 값 | 기준 연도 | 출처 | 시행일 |
|---|---|---|---|---|
| 예: 건강보험료율 | [검색한 값] | 2027 | 국민건강보험공단 | [시행일] |

같은 대화에서 이미 확인한 값은 다시 검색하지 않고 재사용한다.
