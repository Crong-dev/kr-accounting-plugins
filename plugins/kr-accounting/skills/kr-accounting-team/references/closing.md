# 분개 · 결산 · 계정 대사

## 1. 분개 작성 원칙

- 형식: 일자 | 계정과목 | 차변 | 대변 | 거래처 | 적요 | 증빙
- 차변 합계 = 대변 합계를 반드시 계산으로 확인한다.
- 부가세가 있는 거래는 부가세대급금/부가세예수금을 분리한다.
- 적격증빙(세금계산서, 계산서, 신용카드, 현금영수증) 여부를 표시한다. 적격증빙이 없으면 증빙불비 가산세 검토 대상으로 표시한다.

### 주요 결산 분개 유형

| 유형 | 예시 계정 | 확인할 것 |
|---|---|---|
| 미지급비용 | 지급수수료 / 미지급비용 | 용역 제공 완료, 대금 미청구분 |
| 미수수익 | 미수수익 / 이자수익 | 예금 경과이자 |
| 선급비용 상각 | 보험료 / 선급비용 | 보험·임차료 기간 안분 |
| 선수수익 | 매출 / 선수수익 | 수익인식 시점 |
| 감가상각 | 감가상각비 / 감가상각누계액 | 내용연수, 상각방법, 신규·처분 자산 |
| 대손충당금 | 대손상각비 / 대손충당금 | 채권 연령분석, 기대신용손실(K-IFRS) |
| 퇴직급여충당부채 | 퇴직급여 / 퇴직급여충당부채 | DB/DC 구분, 보험수리평가(K-IFRS) |
| 재고자산 평가 | 매출원가 / 재고자산평가충당금 | 실사 차이, 저가법 |
| 외화환산 | 외화환산손실 / 외화예금 등 | 기말 환율(서울외국환중개 매매기준율) |
| 법인세비용 | 법인세비용 / 미지급법인세 | 선납세금 상계, 이연법인세 |

## 2. 월 결산 절차

일정은 회사 마감일 기준(D = 월말 영업일)으로 조정한다.

| 시점 | 작업 |
|---|---|
| D-3 ~ D | 매출·매입 마감, 세금계산서 발행·수취 확인, 법인카드 사용내역 정리 |
| D+1 | 은행·카드 거래 반영, 가지급금·가수금 정리 |
| D+2 | 급여·4대보험·원천세 분개, 미지급·선급 결산분개 |
| D+3 | 감가상각, 재고 마감, 매출원가 확정 |
| D+4 | 계정 대사(아래 3번), 미결 항목 정리 |
| D+5 | 시산표 검토, 전월·예산 대비 증감 분석, 경영 보고 |

결산 체크리스트를 만들 때는 각 항목에 담당자·기한·상태(대기/진행/완료)·근거 파일 칸을 둔다.

## 3. 계정 대사

| 대사 대상 | 비교 자료 |
|---|---|
| 보통예금 | 은행 잔액증명·거래내역 |
| 외상매출금 | 거래처별 보조원장, 채권 조회서 |
| 외상매입금 | 거래처 원장, 매입 세금계산서 합계 |
| 부가세 | 홈택스 전자세금계산서 합계, 카드·현금영수증 매입 내역 |
| 예수금 | 급여대장 원천세·4대보험 금액, 실제 납부액 |
| 가지급금·가수금 | 상대 계정 확인 후 정리, 대표자 가지급금은 인정이자 검토 |
| 관계사 채권채무 | 관계사 장부와 상호 대사 |

### 대사 진행 방법

1. 장부 잔액과 외부 잔액을 나란히 놓는다.
2. 금액·일자·거래처로 1:1 매칭한다. 일자는 ±3일, 금액은 정확히 일치를 기본으로 한다.
3. 매칭되지 않은 항목을 분류한다: 시차(미기표·미결제), 오류(금액·계정 착오), 미확인.
4. 조정 후 잔액이 일치하는지 계산으로 확인한다.
5. 결과물: 대사표(엑셀) + 조정 분개 제안 + 미확인 항목 목록.

## 4. 분기·연 결산 추가 항목

- 재고자산 실사, 고정자산 실사
- 채권·채무 조회서 발송 및 회수
- 퇴직급여충당부채 재계산
- 외화환산, 공정가치 평가(금융상품)
- 손상 검토(유형·무형자산, 영업권)
- 충당부채·우발부채 검토(소송, 보증)
- 법인세비용 및 이연법인세
- 재무제표 및 주석 작성 → `reporting-audit.md`
