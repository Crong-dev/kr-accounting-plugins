## 2. 세무조정 흐름

1. 결산서 확정(손익계산서·재무상태표·이익잉여금처분계산서)
2. 익금산입·손금불산입 / 손금산입·익금불산입 항목 검토
3. 소득금액조정합계표 작성 (유보/사외유출 소득처분 구분)
4. 각 사업연도 소득금액 → 이월결손금 → 비과세·소득공제 → 과세표준
5. 산출세액 (세율 구간은 해당 연도 확인)
6. 세액감면·세액공제 (최저한세 적용 검토)
7. 가산세, 기납부세액(중간예납·원천징수) 차감 → 납부할 세액
8. 법인지방소득세 별도 계산

## 4. 세액공제·감면 검토

중소기업·중견기업 여부에 따라 적용 가능 항목이 달라진다. 아래는 검토 대상 목록이고, 요건과 공제율은 매년 조세특례제한법 개정 내용을 확인한다.

## 5. 이연법인세 (회계)

- 일시적 차이(유보) 목록 → 이연법인세자산·부채 계산
- 실현가능성 검토, 적용 세율은 소멸 예상 연도 기준
- 법인세비용 = 당기법인세 ± 이연법인세 변동

- 세무조정 체크리스트(항목별 검토 결과·금액·근거)
